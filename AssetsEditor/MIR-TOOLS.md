# Wil/Wzl 工具

工具菜单中的“Wil/Wzl解包”和“Wil/Wzl转asset”使用引用的 Mir2Parser 库读取资源。源文件需要同目录下同名的配套索引：WIL/WIX 或 WZL/WZX，也可以直接选择索引文件。

- **解包**：在所选输出目录下创建与资源包同名的子目录，按原始编号输出 `0000000.png` 等图片，以及记录尺寸和偏移的 `schema.json`。空帧输出 1×1 全透明占位图。已有同名输出目录会报错，不覆盖其内容。
- **转 asset**：生成编辑器现有格式的 `.asset`，保留原始帧编号、空帧和偏移。可设置密码、选择是否压缩。覆盖已有文件前会确认，只有全部转换成功才替换目标文件。
- **调色板**：可选 768 字节 RGB 或 1024 字节 BGRA 调色板；留空使用资源自带或解析库默认调色板。仅影响索引色图片。
- **黑底透明效果**：默认关闭。启用后调用解析库的黑底 Alpha 转换，对已有原生 Alpha 的图片保持原有处理规则。

两个工具均在后台处理，显示进度、帧数和状态，支持取消。取消或失败会清理本次未完成的输出。关闭正在工作的窗口会先取消任务，等待当前帧或写入批次结束后再关闭。

“导入资源”对话框增加“Wil/Wzl导入”。此模式选择单个资源包，文件过滤、子目录、附加数据以及位图渲染选项禁用，直接使用解析出的像素和偏移：

| 导入方式 | 原始帧 0 对应的位置 |
| --- | --- |
| 追加 | 当前 asset 末尾 |
| 覆盖 | 当前 asset 的编号 0 |
| 替换 | 编辑器当前选中的编号 |

空帧也占用编号。覆盖和替换不会删除导入范围之外的资源。导入当前 asset 使用分批提交；取消或失败时已经写入的批次会保留，关闭对话框后编辑器刷新显示。普通文件导入的“子目录”选项同样禁用，仅目录导入可以启用。

验证方式见 [UI 与转换测试](../tests/UiSmoke/README.md)。
