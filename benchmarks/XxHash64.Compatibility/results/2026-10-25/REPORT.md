# 内部 XXH64 替换验证（2026-10-25）

GameResource.Package 0.2.2 的文件内容和 Meta 校验已替换为内部 XXH64。标准算法、种子 0、数值结果和小端存储均保持不变，磁盘格式仍为 2。生产库不再引用 System.IO.Hashing；参考程序集仅供独立兼容性工具使用。

## 正确性与兼容性

- 主测试集 **104/104 通过**，其中新增 24 项 XXH64 测试，包括固化参考向量、条带/块边界、分段、快照、并行独立实例和程序集依赖检查。
- 对照 System.IO.Hashing 10.0.0：**5,088 组输入、68,007 次分段快照、8,515 种短输入切分**，所有结果一致。
- 输入覆盖空数据、随机字节、全零、全 255、递增序列、不对齐切片，以及 32 字节条带、64 KiB 块和 1 MiB 附近的边界。
- **4,295,032,876 字节**累计输入验证通过，结果为 `D15E31AD0EB7732D`。复用 64 KiB 数组，不生成大文件，覆盖超过 32 位长度范围的累计状态。
- **256 个并行独立实例**与原实现结果一致。单个累计对象不支持并发修改；资源库每个写入/校验操作使用独立对象。
- 对两个此前由原实现写入的资源包执行完整 Verify，逐一校验全部文件内容和 Meta：

| 旧资源包 | 文件数 | 本次完整 Verify 耗时 |
| --- | ---: | ---: |
| `artifacts/package-benchmark-v02-release-500k/none.pkg` | 500,000 | 4.202 秒 |
| `artifacts/package-benchmark-v02-release-500k/lz4.pkg` | 500,000 | 5.073 秒 |

旧资源包只读打开，没有重写；这些耗时是本次运行的观测值，未清除系统文件缓存，不代表冷盘性能。

## 哈希性能

环境：Intel Core i7-13700KF、Windows 10.0.28000、.NET 10.0.12、Release x64。性能阶段绑定逻辑处理器 0，`DOTNET_TieredCompilation=0`。每项校准约 100 ms，7 轮随机交错执行，以下为中位数。随机输入数组复用，不含磁盘 I/O、解压、解码，包含调用委托和循环开销。

一次性校验：

| 输入大小 | System.IO.Hashing | 内部 XXH64 | 每次托管分配（两者） |
| --- | ---: | ---: | ---: |
| 0 B | 4.25 ns | 4.24 ns | 0 B |
| 32 B | 7.77 ns | 7.26 ns | 0 B |
| 256 B | 20.82 ns | 18.52 ns | 0 B |
| 4 KiB | 254.90 ns | 208.34 ns | 0 B |
| 64 KiB | 3,950.67 ns | 3,199.33 ns | 0 B |
| 1 MiB | 62,616.10 ns | 50,787.19 ns | 0 B |

流式累计校验，每次新建一个对象，按最多 64 KiB 分段追加后取最终哈希：

| 累计输入大小 | System.IO.Hashing | 内部 XXH64 | 每次托管分配（两者） |
| --- | ---: | ---: | ---: |
| 0 B | 8.91 ns | 11.73 ns | 96 B |
| 32 B | 14.04 ns | 21.49 ns | 96 B |
| 256 B | 28.27 ns | 36.72 ns | 96 B |
| 4 KiB | 277.94 ns | 272.14 ns | 96 B |
| 64 KiB | 4,024.79 ns | 3,313.33 ns | 96 B |
| 1 MiB | 64,414.22 ns | 51,977.80 ns | 96 B |

本机测量中，内部实现的大块校验较快；很小的流式输入较慢，例如 32 B 多约 7.45 ns。不能据此推断整个资源加载按同样比例加速。两者流式分配均为每个校验对象 96 B；内部实现将 32 字节尾部缓冲内联，追加和快照操作本身不分配，内存不随累计输入大小增长。
