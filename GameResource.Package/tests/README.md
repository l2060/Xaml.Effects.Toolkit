# 验证

```powershell
dotnet run --project tests/Game.Asset.Package.Tests.csproj -c Release
dotnet run --project tests/Game.Asset.Package.Tests.csproj -c Release -- --large
```

控制台验证器无需测试框架依赖，任何失败均返回非零退出码。每个用例使用独立临时项目，并在结束时关闭句柄、清理文件。

2026-10-26，Release 下35/35通过（含大文件），总耗时60.7秒。覆盖：

- 八种Meta类型、明确类型标注、空数组、规范化编码、溢出及无效格式。
- YAML相对路径、多级prefix、严格配置项、忽略规则、孤立sidecar、重复映射。
- 压缩/未压缩、加密/公开四种组合的构建和完整校验。
- Meta-only覆盖、删除源文件保持继承状态、完整覆盖时Meta状态替换。
- 目录扫描、头部时间排序、相同时间的相对路径排序、Unicode路径。
- 路径索引分页、跨保护页的Meta、缓存关闭。
- 同步/异步并发、取消后的继续读取、结果与流的生命周期。
- 内存映射、范围读取、缓冲上限、头部/Meta/内容损坏、截断。
- 源内容在扫描后变化、取消、未知Tag不发布产物或成功记录。
- 多分包共享Tag和时间、编码策略变化、零第三方程序集依赖及LZ4许可证。

大文件用例使用长度 `2^32 + 12345` 的稀疏**源文件**，四种编码组合均实际遍历全部内容进行摘要、构建和构建后的Verify。未压缩输出实际超过4GiB，不依靠只伪造一个大偏移完成测试。验证2GiB/4GiB前后、文件尾、跨块表页，以及内存映射访问文件尾。

大文件四种组合在本机分别耗时18.2秒、16.1秒、11.8秒、11.6秒（原始、AES、LZ4、LZ4+AES）。这些数字是功能用例耗时，不是独立构建性能基准。运行时应预留至少5GiB可用临时空间；Windows使用稀疏文件API创建源，其他平台依赖文件系统对扩展文件的行为。
