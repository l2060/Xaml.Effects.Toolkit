# Game.Asset.Package 格式 1

所有整数为小端；偏移、总长度、块数量、记录数量采用非负 Int64。禁止直接序列化托管结构体。新 Magic 为 `GASSET01`，不读取旧 `GRPKG002` 文件。

## 文件头（4096 字节）

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 8 | GASSET01 |
| 8 | 4 | 版本 1 |
| 12 | 4 | Flags，0=内容公开，1=内容加密 |
| 16 | 16 | TagId，Guid.TryWriteBytes 的标准 .NET 字节布局 |
| 32 | 8 | UTC DateTime ticks |
| 40 | 4 | 块大小，64 KiB–1 MiB 的二次幂 |
| 44 | 4 | PBKDF2 次数，公开模式为 0 |
| 48 | 8 | 完整文件长度，必须等于实际长度 |
| 56 | 8 | 索引记录数量 |
| 64 | 8 | 目录区原始长度 |
| 72 | 8 | Meta 区原始长度 |
| 80 | 8 | 块表原始长度 |
| 88 | 8 | 内容区起始偏移 |
| 96 | 16 | 每物理文件独立随机盐 |
| 112 | 16 | 保留 |
| 128 | 32 | HMAC-SHA256(masterKey, 前128字节) |
| 160 | 32 | SHA256(前160字节) |
| 192 | 3904 | 保留 |

没有 PackageId、空闲列表、分配长度、保存序号或双头提交。

## 前置区域

目录、Meta、块表依次紧邻文件头。各区都按 65536 字节独立保护；每页保存密文及其后 16 字节 GCM tag，尾页按实际长度保存。零长度区没有页。

`ProtectedLength(L) = L + ceil(L / 65536) * 16`，加法和乘法必须 checked。目录偏移是 4096，Meta 偏移是目录末尾，块表偏移是 Meta 末尾，内容区起点为块表末尾向上 8 字节对齐。

保护后的位置由原始页号直接计算，不需要把整个区域载入内存。运行库可以常驻目录，也可以按需读取同一种布局。

## 目录记录（128 字节）

目录原始数据为全部定长记录，随后是按记录顺序紧密拼接的 UTF-8 路径。记录按路径 UTF-8 字节序严格递增。

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 8 | 路径在目录原始数据中的偏移 |
| 8 | 4 | 路径 UTF-8 长度，1–4096 |
| 12 | 1 | 0=完整资源，1=Meta-only |
| 13 | 1 | bit0=有Meta，bit1=内容分块 |
| 14 | 2 | 保留，0 |
| 16 | 8 | 内容原始长度 |
| 24 | 8 | 连续内容绝对偏移；分块内容为0 |
| 32 | 8 | 内容实际存储长度（分块时为各块之和） |
| 40 | 8 | Meta 在 Meta 原始区域中的偏移 |
| 48 | 4 | Meta 编码长度，上限1MiB |
| 52 | 4 | 保留，0 |
| 56 | 8 | 该资源的首块全局序号 |
| 64 | 8 | 块数量 |
| 72 | 32 | 原始完整内容 SHA-256 |
| 104 | 24 | 保留，0 |

Meta-only 必须有 Meta，所有内容字段及摘要为零。完整空资源仍保存空序列 SHA-256。没有 Meta 时偏移和长度为零；空 Meta 是有效的8字节对象。路径区必须紧密覆盖，禁止重复键和非规范路径。

## 块描述符（32 字节）

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 8 | 数据块绝对文件偏移 |
| 8 | 4 | 存储字节数，含可选16字节认证标签 |
| 12 | 4 | 原始字节数 |
| 16 | 8 | 全包唯一的块序号，等于块表记录位置 |
| 24 | 1 | 0=原始块，1=LZ4 |
| 25 | 7 | 保留，0 |

压缩或加密资源使用块表；未压缩且未加密资源保存连续原始字节。块数量由原始长度和块大小决定，最后一块可短于块大小。块可以在内容区交错存储，通过块表直接定位。未获得压缩收益时写入 codec=0。未来编码增加新 ID，旧读取器拒绝不支持的块。

## Meta

头为 ASCII `AMTA`（4字节）和字段数 Int32（4字节）。之后是每字段24字节描述符，再是紧密拼接、按UTF-8排序的键名，最后是按字段顺序排列、起点8字节对齐的值。

描述符：keyOffset:Int32、keyLength:Int32、valueOffset:Int32、valueLength:Int32、elementCount:Int32、type:Byte、reserved:3Bytes。偏移相对 Meta 对象开头。没有末尾填充；所有键、值的位置必须符合规范布局。

类型ID：1=string、2=int64、3=double、4=bool、5=string[]、6=int64[]、7=double[]、8=bool[]。标量 elementCount=1。字符串为 UTF-8；整数和double各8字节；bool只允许字节0或1。数值和bool数组连续存储。字符串数组保存 N+1 个 Int32 相对值区偏移，后跟 UTF-8 字节；第一个偏移等于偏移表长度，最后一个等于值区长度。禁止非有限double。

## 密钥、nonce 和 AAD

加密 masterKey：PBKDF2-SHA256(password, salt, iterations, 32)，迭代数限制100000–10000000。

公开保护 masterKey：HMAC-SHA256(UTF8("Game.Asset.Package public index protection v1"), salt)。这个密钥可公开推导，只用于隐藏明文，不提供保密性或发布者身份认证。

域：1=目录，2=Meta，3=块表，4=资源内容。前三个域始终使用GCM；域4仅在内容加密时使用。目录/Meta/块表的序号为区域内页号，内容的序号为全包块号。

每1024个序号换一个子密钥：HKDF-SHA256(masterKey, outputLength=32, salt=empty, info)。info为16字节：domain:Int32、reserved:Int32=0、group:Int64，其中group=sequence/1024。最大1MiB块时每子密钥处理不超过1GiB原始数据。

nonce为12字节：domain:Int32 + sequence:Int64。

AAD为40字节：TagId:16、domain:Int32、sequence:Int64、rawLength:Int32、codec:Byte、reserved:3Bytes=0、encodedPlainLength:Int32。

每个包随机盐必须重新生成；不允许在相同主密钥和序号下重写不同明文。AAD不绑定物理偏移，允许CLI先并行编码，再分配最终位置。路径和资源描述受目录页认证保护。

## 发布与读取

构建写入临时文件，回填前置区域及最终头，Flush后关闭并重命名。内容和Meta不能原地编辑。资源包加载后视为不可变。完整缓冲读取和Verify校验原始内容SHA-256；流及局部读取仅检查被访问块的结构和GCM认证。
